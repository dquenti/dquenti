### What this GitHub is about

Health data contains insights that matter — for patients, for clinicians, for policy-makers. Most of those insights never leave the spreadsheet.

This repository series changes that. I take open public health datasets and build analyses that are:

- **Methodologically rigorous** — reproducible code, documented sources, appropriate statistical methods
- **Clearly communicated** — each notebook opens with one question and closes with evidence-based findings, not conclusions the data cannot support
- **Actionable** — every notebook includes a one-page policy brief in PDF format with key findings and implications
